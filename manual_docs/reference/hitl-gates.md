# Справочник HITL-гейтов

[Назад к оглавлению](../index.md)

## 🎯 Назначение

Полный перечень HITL-гейтов в pipeline скилла `maestro` и вариантами ответов.
Decision gates (шаги 10, 12, 17) — явный вопрос с вариантами (a)/(b)/(c).

## 📖 Протокол

1. **Язык:** все вопросы и варианты — только на русском.
2. **Показать контекст** перед вопросом (diff, список задач, git log).
3. **Задать структурированный вопрос** (a)/(b)/(c), не «Continue?».
4. **Дождаться ответа** — молчание ≠ approval.
5. **После ответа:** Approve → следующий шаг · Revise → назад · Reject → STOP.

> ⚠️ «Continue» / «Proceed» / «Давай» **не** являются approval для последующих
> гейтов. Ответ переводит pipeline ровно на один шаг; следующий гейт требует
> отдельного ответа.

## 📖 Гейты feature-маршрута

| Шаг | Гейт | Варианты |
|---|---|---|
| 0 | Загрузка Project Context | (a) загрузить/подтвердить · (b) создать/обновить · (c) пропустить · (d) отмена |
| 1 | Маршрут | (f) feature · (b) bugfix · (c) отмена |
| 1.5 | Режим | (a) efficient · (b) interactive · (c) отмена |
| 2 | Pre-flight | (a) да · (b) отмена · (c) skip в interactive |
| 7 | Категория фичи | (a) сложная/архитектурная · (b) простая · (c) отмена |
| 10 | Spec утверждён | (a) Approve · (b) Revise → шаг 8 · (c) Reject |
| 12 | Plan утверждён | (a) Approve · (b) Revise → шаг 11 · (c) отмена |
| 17 | Pre-PR | (a) Approve merge · (b) Fix → шаг 13 · (c) отмена |

## 📖 Гейты bugfix-маршрута (debug sub-pipeline)

| Шаг | Гейт | Варианты |
|---|---|---|
| D2 | Гипотеза утверждена | (a) да → probe · (b) новая гипотеза → D1 |
| D6 | Гипотеза подтверждена | (a) да · (b) нет → D1 |
| D7 | Переход к фиксу | (a) да → план · (b) отмена |

## 💡 Особые случаи

- **Spec Review (шаг 9):** оркестратор обязан предложить его для сложных фич;
  для архитектурных — обязателен, отказаться нельзя. Шаг 10 не наступает, пока
  пользователь не ответил.
- **Trivial fix (1–2 строки):** maestro не используется — redirect на `@haiku`.
