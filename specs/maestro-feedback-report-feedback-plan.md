для сбора комментариев пользователя к отчёту (запись в секцию `Пользовательский
фидбек`).

### 1. `skills/maestro-feedback-report/SKILL.md` (создать)

Содержимое — перенос текущей команды `commands/maestro-feedback-report.md`,
убрать последний блок "Завершение" (HITL гейт остаётся в команде).

**Что переносим:**
- YAML frontmatter: `name: maestro-feedback-report`, description
- Шаги 1–2: определить текущую сессию, собрать фактуру из диалога
- Шаг 3: дополнить данными из логов плагина
- Шаг 4: собрать отчёт (создать каталог + запись файла)
- **Блок `## Безопасность`:** агрегация sanitizer-событий из логов +
  упоминания безопасности из диалога (без деталей, SEC-4b).
- В конце: "Отчёт сохранён в `<путь>`" — без HITL

**Что НЕ переносим:**
- HITL-гейт "(a) посмотреть/дополнить — (b) ок" — остаётся в команде
- HITL-гейт сбора пользовательского фидбека — в команде

### 2. `commands/maestro-feedback-report.md` (заменить)

Новая структура (точный текст шага — в команде, ниже краткая выжимка):

```markdown
Шаг 2. HITL: запрос фидбека

1. Показать выжимку: Session ID, задача, ключевые находки.
2. Security summary: sanitizer.redacted / access_policy.blocked.
3. Запрос: "Нужно ли исправить фактуру?" →
   - Да: описать правку → перезапустить skill + сохранить фидбек в перезаписанный отчёт
   - Нет: ввести рекомендации (Enter = пропустить)
4. Рекомендации → дописать `## Пользовательский фидбек` в конец отчёта
5. (Enter) → секцию НЕ создавать
```

**Важно:** точный текст HITL-шага — в команде. Спека / план не дублируют его, 
см. DRY-принцип.
4. Если нажат Enter (без текста) → секцию НЕ создавать.
5. Сообщи: "Отчёт сохранён в `<путь>`. Комментарии ✓ / пропущены"."
```

## Верификация

- Команда `@maestro-feedback-report`:
  - Запускает скилл `maestro-feedback-report` → отчёт создан
  - Показывает выжимку из отчёта
  - Запрашивает фидбек → ввод текста = секция добавлена
  - Enter без ввода = секция НЕ создана
  - Формат отчёта = прежний + опциональная секция фидбека
- Скилл `maestro-feedback-report` (без HITL):
  - Запускается через `skill maestro-feedback-report`
  - Генерирует отчёт без HITL-гейтов
  - Может быть вызван сабэджентом через `task` tool
