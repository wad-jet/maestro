## Постановка

В опроснике `/maestro-init` для нового проекта готовые варианты перечисляются
в тексте вопроса, но не предлагаются для выбора:

- **Задача 2 — опрос по 14 категориям** (`skills/maestro-init/SKILL.md:66-84`):
  предписано «задаёт один-два конкретных вопроса в интерактивном режиме» — без
  указания предлагать готовые варианты через вопросный инструмент. Варианты из
  текста категорий (напр. тип проекта, стратегии тестирования, окружения)
  остаются просто текстом, выбора нет.
- То же относится к M1 (`SKILL.md:158`, «введите ID / auto / оставить текущую»)
  и §14 Commands (`init-context.md:118-120`, auto / none / явная) — варианты
  перечислены, но не предлагаются на выбор.

Желаемый формат: если вопрос предполагает готовые ответы — предлагать их через
вопросный инструмент (radio — одиночный, checkbox — множественный) + пункт
«свой вариант»; открытые вопросы остаются свободным текстом.

## Изменения

### 1. `skills/maestro-init/SKILL.md`

**Задача 2 (строки 66-84).** Дополнить протокол опроса: модель сама определяет,
предполагает ли вопрос готовые варианты ответа. Если да — задаёт вопрос через
вопросный инструмент: radio (одиночный) или checkbox (множественный), с пунктом
«свой вариант» (свободный ввод). Варианты, перечисленные в тексте категории,
предлагаются на выбор, а не остаются только текстом. Если готовых вариантов нет —
открытый вопрос.

**M1 (строки 144-167).** Шаг 3: вопрос по каждому агенту задаётся через
вопросный инструмент (radio). Варианты: кандидаты моделей из D2 + `auto`
(ключ `model` не пишется) + «оставить текущую» (если агент уже настроен) +
«свой вариант» (ручной ввод ID).

**Задача 2 / §14 Commands (строки 75-77).** Значение команды (`auto` / `none` /
явная) — через вопросный инструмент (radio) + «свой вариант» (ввод команды
вручную). Определение **набора** команд (какие из TEST/BUILD/E2E/LINT/…) —
checkbox. Radio и checkbox не смешивать.

### 2. `skills/maestro-init/init-context.md`

§14 (строки 118-120): пометить, что `auto` / `none` / явная команда — это
selectable-варианты для вопросного инструмента (не текст).

### 3. Синхронизация доков (sync-правило AGENTS.md)

- `manual_docs/tutorials/setup-project.md:152` — описание M1-вопроса: «выбор из
  вариантов» вместо «(введите ID / `auto` / оставить текущую)».
- `manual_docs/reference/model-selection.md:77-78` — 7 вопросов задаются через
  вопросный инструмент с вариантами.
- §14 в `manual_docs/` — описание значений (явная команда / `auto` / `none`) в
  `manual_docs/explanation/project-context.md:70-79`. При необходимости дополнить.
